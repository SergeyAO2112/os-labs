## Условие

Родительский процесс создаёт дочерний процесс.

Первая строка, которую пользователь вводит в консоль родительского процесса, содержит имя файла. Имя файла передаётся дочернему процессу при его запуске.

Родительский и дочерний процессы реализованы отдельными программами.

Пользователь вводит команды вида:

```text
число число число<конец строки>
```

Родительский процесс передаёт введённые данные дочернему процессу через `pipe`, подключённый к стандартному вводу дочернего процесса.

Дочерний процесс вычисляет сумму чисел каждой введённой строки и записывает результат в указанный файл.

Тип чисел — `int`. Количество чисел произвольное.

## Файлы

- `parent.c` — программа родительского процесса.
- `child.c` — программа дочернего процесса.
- `209_Алексеев_Lab1.pdf` — отчёт по лабораторной работе.

## Компиляция

Для компиляции программ выполнить:

```bash
gcc -Wall -Wextra -Werror child.c -o child
gcc -Wall -Wextra -Werror parent.c -o parent
```

## Запуск

Запустить родительский процесс:

```bash
./parent
```

После запуска первой строкой необходимо ввести имя файла, в который будут записаны результаты:

```text
result.txt
```

После этого можно вводить целые числа, разделённые пробелами:

```text
10 20 30
-10 20 -5
100 -200 50
```

Для завершения ввода используется `Ctrl+D`.

Результаты вычислений будут записаны в указанный файл.

Например, для приведённого выше ввода содержимое `result.txt` будет:

```text
60
5
-50
```
